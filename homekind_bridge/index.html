Home connection

Your home, connected.

Choose home readings, camera status, doorbells and personal sensors for HomeKind.

Getting ready…

1 · Connect your household

Pair with HomeKind

In HomeKind, open Admin → Devices → Connect Home Assistant, then copy the pairing code.

The code lasts 10 minutes. Create it once this app is installed.
2 · Choose your readings

Select devices & sensors

Only selected, supported readings are shared. Camera status is shared here. Live viewing has a separate choice below. Health values require each person to connect their sensor in HomeKind → My sharing.

Loading your Home Assistant sensors…

Connect a physical button

Select its separate press reading above. In Home Assistant, create an automation triggered by this button’s MQTT device action. Have it fire the event homekind_button with source_entity_id set to the button’s battery entity ID, and action set to single, double or hold to match the chosen trigger.

Press each action once so Home Assistant can discover it. Save the automation, then use HomeKind → Settings → Pilot checks to observe two presses. Battery readings alone do not connect a press. Full steps and an example are in this app’s Documentation tab.

3 · Home controls

Lights & plugs

HomeKind can send On / Off requests only to selected devices whose controls you enable in HomeKind. Reported states come back from Home Assistant.

4 · Live camera view

Choose cameras for live view

Allow live viewing for selected cameras. The home owner chooses viewers in HomeKind. Viewing stops when its window closes; HomeKind does not record the feed.

After connecting, return to HomeKind → Admin → Devices to add each selected sensor and assign its room. No Home Assistant password is entered into HomeKind.
