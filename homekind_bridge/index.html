Home connection

Your home, connected.

Choose home readings, camera status, doorbells and personal sensors for HomeKind.

Getting ready…

1 · Connect your household

Pair with HomeKind

In HomeKind, open Admin → Devices → Connect Home Assistant, then copy the pairing code.

The code lasts 10 minutes. Create it once this app is installed.
2 · Choose your readings

Select devices & sensors

Only selected, supported readings are shared. Camera status is shared here. Live viewing has a separate choice below. Health values require each person to connect their sensor in HomeKind → My sharing.

Loading your Home Assistant sensors…

Connect a physical button

Select the button’s separate press reading above and save. Aqara buttons connected through Zigbee2MQTT use the actions already recognised by Home Assistant. No automation is needed.

Try single, double, triple and hold where supported. If an action is new, allow up to 30 seconds for discovery. Add the press reading in HomeKind → Devices, then open Settings → Pilot checks. This records presses only; notifications are chosen separately.

Save your selected button to check its direct connection.

3 · Home controls

Lights & plugs

HomeKind can send On / Off requests only to selected devices whose controls you enable in HomeKind. Reported states come back from Home Assistant.

4 · Live camera view

Choose cameras for live view

Allow live viewing for selected cameras. The home owner chooses viewers in HomeKind. Viewing stops when its window closes; HomeKind does not record the feed.

5 · TV & audio

Media controls & now playing

Choose players for play/pause, volume and favourites in HomeKind. This shares current track titles, artists and available favourite names with people who can view that room. Media addresses and artwork stay here. Enable each player in its HomeKind media choices to allow controls.

After connecting, return to HomeKind → Admin → Devices to add each selected sensor and assign its room. No Home Assistant password is entered into HomeKind.

Import personal health readings

HomeKind’s own local importer. Preview a CSV report or HomeKind JSON file and keep only selected daily readings. Garmin login and automatic sync are not available; they require approved Garmin API access.

For Garmin, export a daily report from Garmin Connect → Reports. Select its date and reading columns below. Activity lists, ZIP and FIT files are not supported. JSON uses date, steps, sleep_minutes and resting_heart_rate.

Loading local health import…

The raw report is not saved or uploaded. This importer keeps only each metric’s latest reading for seven calendar days. Removing a source clears its current values; Home Assistant manages its own recorded history and backups. In HomeKind, select these sensors, add them under Devices and connect them to yourself in My sharing before any values are collected there.
